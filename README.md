# HealthyLine AI Chat Admin & Viewer

Панель управления и просмотра диалогов клиентов HealthyLine Support с интеграцией через API n8n.

## Что делает проект

- **Двухоконный интерфейс**: удобный просмотр списка клиентских обращений слева и полной истории переписки справа.
- **Интеграция через n8n API**: приложение работает через защищенный обратный прокси / шлюз n8n:
  - `GET /api/chats` — получение списка всех диалогов
  - `GET /api/chat?id=<session_id>` — получение сообщений конкретного чата
- **Безопасность данных**: браузер не имеет прямого доступа к базе данных Supabase. Все учетные данные и логика хранятся на стороне сервера / n8n.
- **Защищенный вход**: встроенный шлюз авторизации для менеджеров и операторов.

## Как использовать

1. **Загрузите файлы в репозиторий GitHub** (ветка `main` или `master`).
2. **GitHub Actions автоматически соберет проект**:
   - Выполнит `npm install`
   - Соберет продакшен-версию `npm run build`
   - Сгенерирует и сохранит готовую папку `dist/` прямо в репозиторий.
3. Подключите собранную папку `dist/` или деплой на ваш хостинг / Cloudflare / Netlify / Vercel.

## Локальный запуск (для разработки)

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка TypeScript
npm run lint

# Сборка проекта
npm run build
```
